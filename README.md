# Taskie — Offline Task Manager

A fast, offline-first task manager that runs entirely in your browser. No backend, no accounts, no internet required. Built for busy people who need to track tasks daily without the overhead of bloated apps.

## Why Taskie?

I work in a fast-paced industry where I juggle multiple tasks every day — some one-off, some recurring. Remembering everything got too cumbersome, and existing tools were either too heavy, required accounts, or needed internet. Taskie solves that: open the file, add tasks, get things done.

## What It Can Do

- **Dashboard** — at-a-glance view with stat boxes and auto-organized lists (overdue, today, next 7 days, next 30 days, custom range)
- **Tasks** — quick-add, inline edit, subtasks, due dates, status tracking, search, sort
- **Repeat Tasks** — flexible recurrence (daily, weekly, monthly) with instance tracking and completion
- **Settings** — export/import data, toggle features, keyboard shortcuts

## Tech Stack

Vue.js 3 (CDN or local copy) + IndexedDB + Pure CSS


## Run It

Open `index.html` in any browser. No build step, no terminal needed.
